# TASK

A lightweight, browser-based daily task planner.

## Publish with GitHub Pages

1. Create a public GitHub repository (for example, `TASK`).
2. Upload `index.html` to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, then **main** and **/(root)**, and save.
5. Open the Pages URL shown in GitHub after deployment.

## Data storage

Task data is stored in the browser's `localStorage`. It is **not synchronized** across browsers or devices. Use the app's JSON export to back up your data before changing browsers or clearing site data.
